Reproducibility. This sample is corpus demo-1k, generated by CadQuarry v— from seed —. Regenerate it bit-for-bit:

cadquarry generate --seed — --count 1000 --out demo-1k/

The generator + seed is the canonical artifact; the data here (and the larger corpora on Hugging Face) is a convenience. Generator code is Apache-2.0; generated data is CC0-1.0.
